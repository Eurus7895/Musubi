What changed in Step 4

Budgeted packing

fit_context protects the system prompt, first task, and recent turns, then packs old tool results until the conversation fits the budget.

Compress before trim

Old tool outputs go through the same native reversible compressors before any lossy context-trimmed stub is used.

Pairing preserved

Tool result blocks stay in place with their tool_use_id. Any lossy view keeps a retrieve marker when a ref is available.
