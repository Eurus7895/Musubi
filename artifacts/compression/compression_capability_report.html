What changed in Step 3

Native structure

JSON now emits shape, counts, path stats, and bounded samples. Python uses AST signatures instead of body text.

Pattern views

Logs are grouped by normalized patterns with first and last examples. Text keeps headings and bounded section snippets.

Still reversible

Every lossy view stores the original by content hash. The retrieve marker points to the exact verbatim payload.
